# R128

## Directory content

|file           |description                                      |
|---------------|-------------------------------------------------|
|_content_      |files related to image content                   |
|_linux_        |entry area source for GNU Assembler on Linux     |
|_dos_          |entry area source for NASM on DOS                |
|_cpm_          |entry area source for ASM and Z80ASM on CP/M     |
|dump           |parameterized, filtered hexdump (Bash script)    |
|insdata        |inserts content into data area (Bash script)     |
|mkimages       |makes images and inserts entry area (Bash script)|
|r128ex.bin     |binary file with entry area                      |
|r128exfd.img.gz|gzipped 1.44 MB disk image                       |
|r128exrm.img.gz|gzipped 27256 EPROM image                        |
