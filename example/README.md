# R128 ROM filesystem

## Directory content

|file          |description                                 |
|--------------|--------------------------------------------|
|_content_     |files related to image content              |
|_linux_x86_   |entry area source for GNU Assembler on linux|
|_dos_x86_     |entry area source for NASM on DOS           |
|_cpm_8080-z80_|entry area source for ASM and Z80ASM on CP/M|
|insdata       |inserts content into data area              |
|mkimages      |makes images and inserts entry area         |
|r128ex.bin    |binary file with entry area                 |
|r128exfd.img  |1.44 MB disk image                          |
|r128exrm.img  |27256 EPROM image                           |
